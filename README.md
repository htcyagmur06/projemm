# projemm
Otoparka giren sürücüler çoğu zaman boş yer aramak için aynı alanda defalarca dönmek zorunda kalıyor. Bu durum zaman kaybına, gereksiz yakıt tüketimine, trafik yoğunluğuna ve sürücülerde strese yol açıyor.

AkıllıPark, sürücü otoparka girmeden önce boş yerleri görebilmesini ve girişte kendisine otomatik olarak bir yer atanmasını sağlayan web tabanlı bir sistemdir. Amaç, otoparkta boş yere dolaşmayı ortadan kaldırmaktır.
